# AI 行业日报看板（AI Daily Dashboard）

> 每天 5 分钟，看懂今天 AI 圈发生了什么。

一个**纯前端、零依赖、单文件**的 AI 行业日报看板页面。深色科技风视觉设计，适合科技视频录屏、直播封面及个人播客开场使用；包含新闻卡片、重要程度筛选、"阅读完成"交互与今日趋势面板。

## 1. 项目名称

**AI 行业日报看板（AI Daily Dashboard）** —— 单文件 HTML 演示项目。

## 2. 项目功能介绍

- **顶部标题区（B站视频封面风格）**
  - 大号渐变标题「AI 行业日报」
  - 醒目副标题：5分钟看懂今天AI圈发生了什么
  - 自动更新的当前日期徽章（打开页面时由 JS 写入当天日期）
- **今日重点摘要**
  - 三条数字编号摘要，对应下方新闻的三大观察方向（视频生成 / Agent / 开源与端侧）
- **新闻卡片（3 条，层级区分）**
  - 头条卡为「高优先级」，视觉尺寸最大，含话题热度、趋势曲线等装饰信息
  - 其余卡片按优先级降序排列，每条都带「重要程度」标签
- **重要程度筛选**
  - 全部 / 高优先级 / 中优先级 三个筛选按钮，当前选中项高亮
  - 点击后仅展示对应优先级新闻，支持随时切回
- **阅读完成交互**
  - 每张卡片独立维护状态：点击按钮 → 变为「✓ 已完成」，卡片右上角弹出对勾徽章
  - 再次点击可恢复为「阅读完成」并收回对勾
- **今日趋势小面板**
  - 热搜榜单式排行（前 3 名彩色高亮）+ 热度条 + 涨跌方向标记 + 话题标签
  - 桌面端固定于页面右侧，移动端自动移动到新闻列表下方
- **视觉与适配**
  - 深色渐变 + 网格光斑背景、玻璃拟态卡片、入场动画
  - 页面比例适合 16:9 视频录屏；同时完整支持手机宽度单列展示
  - 纯 HTML / CSS / JavaScript 编写，无任何外部库与 CDN，可离线双击打开

## 4. 如何打开网页

方式一（推荐）：**直接双击** `index.html`，用任意现代浏览器（Chrome / Edge / Safari / Firefox）打开即可，无需安装任何东西。

方式二：在项目目录下启动本地静态服务后访问：

```bash
# Python 3
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080

# 或 Node.js
npx serve .
```

## 5. 已实现的交互功能

| 交互 | 行为 |
| --- | --- |
| 点击「阅读完成」 | 按钮文字变为「✓ 已完成」，卡片右上角出现绿色对勾，卡片边框转绿 |
| 再次点击「已完成」 | 恢复为「阅读完成」，对勾隐藏，状态还原（支持反复切换） |
| 点击「全部」 | 恢复显示全部 3 条新闻 |
| 点击「高优先级」 | 仅显示高优先级新闻卡片 |
| 点击「中优先级」 | 仅显示中优先级新闻卡片 |
| 日期徽章 | 打开页面时自动显示当天日期与星期 |
| 窄屏适配 | 手机宽度下新闻列表/摘要变单列，趋势面板移至新闻下方，筛选按钮等宽排列不换行错乱 |

实现说明：已读状态使用卡片自身的 `is-read` 类独立保存；筛选只通过 `card-hidden` 类控制显隐，二者互不干扰——先标记"已读"再切换筛选，切回来时状态依然保留。
